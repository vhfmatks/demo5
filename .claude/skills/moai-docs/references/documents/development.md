# `docs/development.md` — AI와 함께 어떻게 개발했나요?

팀원 기여·AI 검토·수정·재시험·개선 이력을 기록할 때만 읽는다. 제공된 문서 레이아웃을 따르고 기존 문서의 실제 기록은 보존한다.

**작성·갱신 시점:** 작업·리뷰 직후 팀원 3명의 역할과 AI 사용·검증 과정을 실제 근거로 남긴다.

**본문 배치:** 팀원별 작업·리뷰·기여 → Issue → AI 사용 목적 → 변경 코드 → 검증 · 수정 · 재시험 → 반복 작업 개선 전후 비교 → 변경·일정 이력.

- 작업·AI 기록 표: `Issue | 팀원·역할 | AI 사용 목적 | 변경 코드 | 검토 | 수정 | 검증·재시험 | 근거`.
- 개선 비교 표: `반복 작업 | 개선 전 | 개선 후 | 비교 방법 | 실제 결과 / 미측정 | 근거·제약`.

확인자가 실제로 검토한 내용과 PR·커밋·실행 근거를 연결한다. 인간 검토 사례·AI 효과를 만들어 내지 않고 미측정은 미측정으로 표시한다. 긴 AI 출력·로그는 필요한 부분만 evidence로 연결하며 비밀값·개인정보는 보관하지 않는다. AC·TC 상태 판정이 아니라 근거 기록만 하는 경우 다른 매뉴얼을 추가로 읽지 않는다.
