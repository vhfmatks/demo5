# `README.md` — 다른 사람도 실행할 수 있나요?

README를 작성·갱신하거나 실행·문서·근거 링크를 대조할 때만 읽는다. 제공된 문서 레이아웃의 질문·본문 순서를 따른다. 기존 문서의 실제 안내·이력은 보존하며 빠진 항목만 부분 보완한다.

**작성·갱신 시점:** 환경을 준비하며 명령을 적고, 실행 방법·버전 변경 시 갱신한다. 제출 전 새 환경에서 따라 실행해 확인한다.

**본문 배치:**
1. 실행 환경·정확한 도구 버전·고정된 의존성·비밀값 없는 설정 방법. package.json·실제 실행 환경으로 대조하며 비밀번호·토큰은 넣지 않는다.
2. 설치 → 빌드 → 기동 → 시험 → 종료·정리의 실행 명령과 각 단계의 예상 결과. 개발 기동과 제출용 빌드·기동을 구분한다.
3. 팀 관리 docs 7개·주최 측 보안 정책·시험 결과의 문서 지도와 링크.
4. 실제 시험 SHA·실행 결과 위치·새 환경 재현 결과·미검증 / 제약. 상세 시험 기록은 e2e-test와 evidence로 연결한다.
