# `docs/security-policy.md` — 주최 측이 제공한 필수 보안 정책

공식 정책 수령·개정·원문 보존을 확인할 때만 읽는다. 팀 작성 8종과 별도의 필수 원본이다.

보안 기준은 주최 측이 작성·공지한다. **레이아웃 정리 대상에서 제외**하고 제목·본문·SEC 번호를 임의로 추가·수정·삭제하지 않는다. 수령·개정 시 적용 범위를 확인하고 적용·검증 결과는 security-compliance에 남긴다. 미수령은 미수령으로 기록한다.

정책을 검토할 때는 실제 주최 측 원문을 읽는다. 이 참조 파일은 보존 매뉴얼이며 공식 보안 정책을 대신하지 않는다. 적용·검증 기록을 작성할 때만 [security-compliance](security-compliance.md)를 추가로 읽는다.
