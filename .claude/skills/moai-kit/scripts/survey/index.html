02 / 도메인 조립

메뉴와 데이터

도메인 1개 = 메뉴 1개 = 목록·상세·작성·수정 화면 + API + 시험. title(제목)·memo(메모)는 항상 생기므로 그 외 필드만 추가합니다. 참조 필드는 users 또는 앞쪽 도메인만 가리킬 수 있습니다.

이미 있는 도메인은 바꾸지 않습니다(필드 변경은 K migrate 로 직접). 새 도메인만 추가하고, 기존 도메인은 참조 대상으로 쓸 수 있습니다.
