**제목** (하나와 맞아야 한다)

- `[REQ-<번호>] <요약>` 기능 티켓, REQ가 여럿이면 [REQ-25·26]
- `Spec: <요약>` 부모 spec
- `[bug] <화면/API>: <요약>` 버그 접수·진단
- `[improve] <화면/API>: <요약>` 개선 접수
