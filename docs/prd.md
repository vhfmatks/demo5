## 권한 · 데이터 · 상태 규칙

권한 검사는 역할 비교가 아니라 권한 단위로 구현한다(`docs/conventions/rbac.md`, kit init 후 생성). "관리자" = kit 기본 ADMIN 역할.

| 행위 | 역할 | 허용 조건 | 거부 시 |
|---|---|---|---|
| 목록·상세·검색 조회 | 로그인 사용자 | 로그인 | 비로그인: 화면은 로그인 이동, API 거부 |
| 게시글 작성 | 로그인 사용자 | 로그인 | 비로그인 거부 |
| 게시글 수정 | 로그인 사용자 | 본인이 작성한 글 | 거부, 저장값 불변 |
| 게시글 삭제 | 로그인 사용자·관리자 | 본인 글, 또는 관리자 | 거부, 글·댓글 불변 |
| 댓글 작성 | 로그인 사용자 | 로그인, 대상 글 존재 | 없는 글 404 |
| 댓글 삭제 | 로그인 사용자·관리자 | 본인 댓글, 또는 관리자 | 거부, 댓글 불변 |
| 공지 고정·해제 | 관리자 | 관리자 | 거부, 고정 상태 불변 |

| 엔티티 | 필수·고유·참조 필드 | 상태값·허용 전이 |
|---|---|---|
| 게시글(Post) | 제목(필수, 1–100자), 본문(필수, 1–5,000자, 일반 텍스트), 작성자(사용자 참조), 작성 시각, 수정 시각, 고정 여부, 조회수 | 일반 ↔ 고정(관리자만). 삭제 = 완전 삭제(댓글·조회 기록 함께) |
| 댓글(Comment) | 게시글(참조), 작성자(사용자 참조), 내용(필수, 1–500자), 작성 시각 | 작성 → 삭제(완전 삭제). 수정 없음 |
| 조회 기록 | 게시글(참조) + 사용자(참조) 쌍이 고유 | 첫 열람 시 생성, 조회수 = 기록 수 |

- 목록 페이지 크기 20, 정렬 작성 시각 최신순. 고정 글은 페이지마다 맨 위(고정 글끼리 최신순).
- 감사로그: 게시글·댓글 쓰기·삭제와 고정 변경은 kit 감사 규칙에 따라 기록한다.

## 범위 · 제외
