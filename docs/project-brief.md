# 프로젝트 개요 (project-brief)

> 무엇을, 누구를 위해 만드나요? — 주제 공개 후 문제·사용자·범위를 정하고(`/moai-grill`), 개발 뒤 실제 결과로 갱신한다. 범위·역할 변경의 이유도 남긴다.

## 문제 · 대상 사용자

- 프로젝트: `demo5` · 표시 제목 **게시판**
- 문제(사용자 요청 원문 요약): 로그인한 사용자가 게시글과 댓글로 정보를 공유하고, 관리자가 공지할 글을 목록 맨 위에 고정할 수 있는 간단한 게시판이 필요하다.
- 대상 사용자: 로그인 사용자(글·댓글 작성, 본인 글 수정·삭제), 관리자(모든 글·댓글 삭제, 공지 고정·해제). 비로그인 사용자는 이용할 수 없다.
